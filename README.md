# MusicPlayer-Typecho

基于 **APlayer** 的 Typecho 音乐播放器插件。通过在文章中插入 `[music]文件夹名[/music]` 标签，即可嵌入音乐播放器。

---

## 功能特点

- 🎵 **短代码嵌入** — 在文章中用 `[music]歌曲名[/music]` 插入播放器
- 📁 **文件夹管理** — 每首歌一个文件夹，支持音频/歌词/封面文件
- 🌐 **外链支持** — 音频、歌词、封面均可使用外部 URL
- 🎤 **自定义歌手名** — 每首歌可独立设置
- 🌐 **Emo 页展示开关** — 每首歌可独立控制是否出现在 Emo 音乐页面（缺省展示；取消勾选后仅 `[music]` 短代码可播放）
- 🎨 **主题色配置** — 5 种播放器主题色可选
- 🔄 **缓存机制** — 自动缓存音乐目录结构，避免每次加载扫描磁盘
- 🖥 **后台管理面板** — 在 Typecho 后台「管理 → 音乐」中管理歌曲

## 安装

1. 将插件文件夹重命名为 `MusicPlayer`，放入 Typecho 的 `usr/plugins/` 目录
2. 进入后台 → **控制台** → **插件管理**，激活 **MusicPlayer**
3. 激活后会自动创建 `usr/uploads/music/` 目录

---

## 使用

### 准备工作

将音乐文件（mp3, flac, ogg, wav 等格式）放入 `usr/uploads/music/` 下的子文件夹，每个文件夹对应一首歌：

```
usr/uploads/music/
├── 晴天/
│   ├── 晴天.mp3            # 音频文件（必须）
│   ├── 晴天.lrc             # 歌词文件（可选）
│   └── 晴天.jpg             # 封面图片（可选）
├── 七里香/
│   ├── 七里香.flac
│   └── 七里香.jpg
└── 夜的第七章/
    ├── 夜曲.mp3
    ├── 夜曲.lrc
    └── 夜曲.png
```

> **支持的文件格式：**
> - 音频：`flac`, `mp3`, `m4a`, `ogg`, `wav`, `aac`, `wma`
> - 歌词：`lrc`
> - 封面：`jpg`, `jpeg`, `png`, `gif`, `webp`

### 管理歌曲

前往后台 → **管理** → **音乐**：

- **刷新缓存** — 扫描 `usr/uploads/music/` 目录，更新歌曲列表
- **新增歌曲** — 填写歌曲名称、歌手，上传或填写外链（音频/歌词/封面）
- **编辑歌曲** — 修改歌曲名称、歌手、音频/歌词/封面来源
- **删除歌曲** — 删除歌曲及其文件夹
- **Emo 页展示** — 每首歌可独立开启/关闭「Emo 音乐页面展示」（缺省开启；关闭后该歌不出现在 Emo 页，文章内 `[music]` 短代码不受影响）

### 在文章中插入音乐

在文章编辑器中插入短代码：

```
[music]晴天[/music]
```

插件会自动渲染为 APlayer 播放器。

### 外链歌曲

除了本地文件，也可以在管理面板中将歌曲的音频/歌词/封面设置为外部 URL。

## 配置

前往后台 → **设置** → **插件** → **MusicPlayer**：

| 配置项 | 说明 |
|--------|------|
| 默认封面图 | 歌曲无封面时显示的默认图片 URL，留空不显示 |
| 播放器主题色 | 选择 APlayer 默认主题颜色：天蓝 / 淡红 / 草绿 / 灰色 / 墨蓝 |
| 自动播放 | 是否自动播放（注：多数浏览器会限制自动播放） |

```
MusicPlayer/
├── Plugin.php                    # 主插件文件
├── pages/
│   └── manage-music.php          # 后台管理面板（管理 → 音乐）
├── APlayer.min.css               # APlayer 样式
└── APlayer.min.js                # APlayer 脚本
```

---

## 注意事项

- 文件夹名不能包含 `..` 或 `/` 等特殊字符
- 如果修改了 `usr/uploads/music/` 目录中的文件，需要在管理面板中点击「刷新缓存」
- 外链歌曲不会被目录扫描覆盖，写入缓存后自动保留
