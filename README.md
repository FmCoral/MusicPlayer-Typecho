# MusicPlayer — Typecho 音乐播放器插件

基于 [APlayer](https://github.com/DIYgod/APlayer) 的音乐播放器。使用短代码在文章中插入音乐，支持本地文件和外链，每项独立选择来源方式。

## 安装

1. 将 `MusicPlayer/` 整个目录上传至 `usr/plugins/`
2. 进入 Typecho 后台 → **控制台** → **插件**，启用 MusicPlayer
3. 在站点根目录创建 `usr/uploads/music/` 文件夹
4. 放入音乐文件（FTP 或后台直接上传），进入 **音乐** → **音乐播放器**，点击「刷新缓存」

## 音乐文件结构

每首歌独立一个文件夹，放在 `usr/uploads/music/` 下：

```
usr/uploads/music/
├── 歌名1/
│   ├── 歌名1.mp3
│   ├── cover.jpg
│   └── lyric.lrc
├── 歌名2/
│   ├── 歌名2.flac
│   └── cover.png
└── ...
```

### 支持的格式

| 类型 | 格式 |
|------|------|
| 音频 | flac / mp3 / m4a / ogg / wav / aac / wma |
| 歌词 | .lrc |
| 封面 | jpg / jpeg / png / gif / webp |

音质优先级：`flac > mp3 > m4a > ogg > wav > aac > wma`

## 使用方法

在文章中插入短代码：

```
[music]文件夹名[/music]
```

例如——`usr/uploads/music/晴天/` 下有一首歌：

```
[music]晴天[/music]
```

渲染后替换为 APlayer 播放器，支持歌词同步显示。

## 来源方式

每首歌的音频、歌词、封面可**独立选择**来源：

| 方式 | 说明 |
|------|------|
| **上传文件** | 通过浏览器上传到服务器，存在 `usr/uploads/music/<文件夹>/` 下 |
| **外链** | 填写外部 URL（CDN、对象存储等），优先于本地文件 |
| **跳过** | 不设置该项，适用于纯外链歌曲或不需要歌词/封面的场景 |

三种方式可任意组合。例如音频用本地文件、歌词用外链、封面不设置。

## 后台管理

插件设置页集成全部功能，无需独立菜单。

### 新增歌曲

在「新增歌曲」区，对每项（音频/歌词/封面）先选模式再操作：

- **本地** — 出现文件选择框，上传到服务器
- **外链** — 出现 URL 输入框
- **跳过**（歌词/封面适用）— 不设置

### 歌曲列表

表格显示每首歌的名称和三个来源状态（本地/外链/无），每行提供三个操作：

| 操作 | 说明 |
|------|------|
| **▶ 试听** | 新窗口打开音频播放 |
| **✏ 编辑** | 行内展开编辑面板，可切换本地/外链/跳过模式、上传文件或填写 URL |
| **🗑 删除** | 删除磁盘文件夹和缓存记录 |

编辑时自动根据当前数据选择模式（有本地文件默认本地，有外链默认外链），保存后自动更新缓存。

### 删除歌曲

在歌曲列表点击「删除」，自动删除磁盘上的文件夹和缓存记录。

### 刷新缓存

扫描 `usr/uploads/music/` 目录更新歌曲列表。纯外链歌曲（无本地文件）和有元数据的歌曲会被保留，不会因扫描而丢失。

## 插件设置

| 选项 | 说明 |
|------|------|
| 默认封面图 | 歌曲无封面时显示的默认图片 URL |
| 播放器主题色 | APlayer 主题颜色 |
| 自动播放 | 是否自动播放（多数浏览器会限制自动播放） |

## 缓存机制

- 缓存文件 `MusicPlayer.json` 存储在插件目录下
- 每次页面渲染只读缓存，不扫描磁盘
- 同一页面中运行时只会读取一次（静态变量缓存）
- 刷新缓存时保留外链、名称、歌手等元数据
- 纯外链歌曲不会因刷新缓存而丢失

## 常见问题

**Q：既上传了文件又填写了外链，哪个生效？**

外链优先。如果外链留空，自动使用本地文件。编辑时可直接切换模式。

**Q：文章里可以放多个音乐短代码吗？**

可以，每篇文支持多个 `[music][/music]`，各自渲染为独立的播放器。

**Q：FTP 上传和后台上传冲突吗？**

不冲突。文件统一存放在 `usr/uploads/music/` 下。FTP 适合批量管理，后台上传适合偶尔新增单曲。

**Q：歌词怎么用？**

放 `lyric.lrc` 到歌曲文件夹（自动识别），或在编辑区改为外链模式填写歌词 URL。

**Q：纯外链歌曲（无本地文件）刷新缓存会丢失吗？**

不会。插件会自动保留有外链或元数据的缓存条目。

## 目录结构

```
usr/plugins/MusicPlayer/
├── Plugin.php           # 主插件文件（钩子、缓存、创建/更新逻辑）
├── APlayer.min.css      # APlayer 样式
├── APlayer.min.js       # APlayer 核心库
└── README.md            # 本文件
```

缓存文件 `music_player.json` 位于 `usr/uploads/music/music_player.json`，更新插件时不会丢失。
